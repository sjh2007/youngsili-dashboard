개요

영실이 콘솔이란

기관 담당자가 쓰는 youngsili-dashboard.krafte.net과 달리, 이 콘솔은 크래프트 운영팀이 전체 기관을 관리하는 화면입니다.

이 계정으로 할 수 있는 일은 모든 기관의 어르신 개인정보와 결제 정보에 접근하는 것을 포함합니다. 로그인 정보를 공유하거나 개인 기기에 저장하지 마십시오.

이 콘솔이 다른 이유

기관 담당자가 쓰는 youngsili-dashboard.krafte.net은 한 기관의 어르신만 다룹니다. 이 콘솔(ops.krafte.net)은 전체 기관을 총괄 관리자가 관리하는 화면이며, 일반 기관 계정(센터장·전담직원·지원사)에는 이 메뉴들이 보이지 않습니다.

좀비 세션 확인하기

경과 시간이 비정상적으로 긴 항목을 주기적으로 확인하십시오. 정상 통화는 대개 몇 분 안에 끝납니다. 경과 시간이 수 시간, 길게는 며칠 단위로 찍히는 항목은 통화가 끝났는데도 세션이 종료 처리되지 않은 좀비 세션일 가능성이 높습니다.

이런 항목은 통화 채널을 계속 점유한 채로 남아 있어, 실제로 그 기관이 쓸 수 있는 발신 채널 수를 줄이는 실질적인 문제가 됩니다. 이 화면에서 직접 종료하는 기능은 확인되지 않았으므로, 반복적으로 나타나면 통화 ID를 기록해 개발팀에 세션 정리를 요청하십시오.

이 목록에는 실제 담당자의 이메일·전화번호가 그대로 노출됩니다. 화면을 캡처해 외부로 공유하거나 다른 문서에 옮겨 적지 마십시오. 계정 확인이 필요하면 이 화면에서 직접 조회하는 것을 원칙으로 합니다.

계정 삭제 전 확인

  • 본인 확인 — 퇴사·인사이동이 맞는지 기관 담당자에게 재확인
  • 지원사라면 배정된 이용자가 있는지 확인하고, 있다면 다른 지원사에게 재배정 후 삭제
  • 센터장(관리자)이 한 명뿐인 기관이라면 삭제 전 후임 계정을 먼저 생성

#항목내용
1좀비 통화 세션 「진행 중인 통화」에 경과 시간이 수 시간~14일에 달하는 항목이 다수 확인됨. 실제 통화가 아니라 종료 처리가 안 된 세션으로 추정됨. 통화 채널을 계속 점유해 실제 발신 가능 채널 수에 영향을 줄 수 있음. 자세히: 진행 중인 통화
2정액제·정량제 정합성 정기결제 현황은 정액제(월 청구) 기준 화면으로 보이나, 실제 판매 중인 요금은 정량제(선불 충전) 구조임. 두 체계가 이 화면에서 어떻게 반영되는지, 정량제 잔액·충전 이력을 조회할 별도 화면이 있는지 확인 필요. 자세히: 정기결제 현황
3부재중 비율 기관 담당자 문서 작성 중 확인된 사항 — 파일럿 기관의 통화 종료 사유 중 부재중(무응답) 비율이 53%로 정상 종료(45%)보다 높음. 발신 시간대·발신번호 표시 설정을 점검할 필요가 있음
4가입 후 미사용 기관 기관 목록 중 대상자 0명·계정 0~1개인 기관이 다수 확인됨. 가입만 하고 온보딩이 진행되지 않은 상태로 추정됨. 자세히: 기관·계정 목록
5계정 이메일 정책 부재 대시보드 계정 목록에 개인 gmail 등 사설 이메일로 가입된 센터장·지원사 계정이 다수 확인됨. 계정 복구·본인 확인 시 어려움이 있을 수 있어 기관 업무용 이메일 사용을 권장하는 정책 검토 필요
